# Hồ sơ người làm game (giả định, chưa được xác nhận)

- **Đội:** một người, làm cùng AI agent.
- **Công nghệ:** HTML/JS một file, bản web PWA + app Android (WebView); có sẵn server WebSocket (Cloudflare Workers / Node).
- **Nền tảng:** web và Android.
- **Thị trường:** Việt Nam trước, tiếng Việt.
- **Ngân sách:** coi như gần bằng 0 (chưa hỏi).
- **Thế mạnh:** lập trình, tự sinh hình pixel bằng code, đã có game online đang chạy (Giáng Ma Sư).
- **Sở thích:** tu tiên, nhân vật pixel chibi đổi trang phục theo cảnh giới.
